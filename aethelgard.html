System Overview & Game Architecture

Aethelgard: Exoplanet Frontier is a full-stack, real-time multiplayer planetary strategy platform live at aethelgard-game.com. Players take on the role of Planetary Commanders competing to establish resource monopolies, construct orbital transit conduits and outposts, trade with orbital depots, deploy tactical modules, and be the first to reach 10 Victory Points.

Architected around strict server authority, the platform decouples game logic into 19 isolated domain services in Python. State mutations are managed through an authoritative Finite State Machine (FSM) and pure reducer with Token Bucket rate limiting and Redis distributed locks to eliminate concurrency conflicts during high-speed player actions.

The ecosystem integrates full-stack monetization and advertising: Paddle Billing with localized price previews, one-page checkout overlays, and HMAC-verified webhooks alongside a multi-tiered NitroPay ads system. Background Celery workers handle turn expiration timeouts, AFK player kicks, bot takeovers, and placement-based ELO rating calculations.

Core System Architecture & Capabilities

Real-Time WebSockets & Authoritative Reducer

Bidirectional duplex communication powered by Django Channels (ASGI) and Redis PubSub. Commands are sequenced per room queue, validated against strict contracts, and executed via a pure state reducer with Fog of War privacy filtering.

Asynchronous Celery & Placement ELO

Celery workers backed by Redis handle automated turn timeouts, fallback moves, AFK skip/kick logic, stale lobby garbage collection, and post-match placement-based ELO calculations (+10 / +7 / -6 / -10) with global leaderboards.

Paddle Billing & SaaS Monetization

End-to-end Paddle Billing pipeline with localized client PricePreview, one-page checkout overlay modals, 1-day free trials, self-service customer portal session generation, and HMAC-SHA256 verified webhook event synchronization.

NitroPay Waterfall & Multi-Tier Ads

Integrated NitroPay ad delivery engine featuring 160x600px desktop skyscraper units, responsive auto-centering 320x50px mobile units, 5-second guest entry video reward ads, and resilient procedural offline fallback banners.

Security Hardening, Throttling & Audit Logs

Single-use 60s WebSocket handshake tickets, Token Bucket rate limiting, 150ms per-player cooldowns, robotic anomaly detection triggering CAPTCHA challenges, and immutable PostgreSQL security audit logging.

Automated Testing Suite & CI/CD Pipeline

Comprehensive test suite spanning 240 unit, integration, and Hypothesis property-based fuzz tests, coupled with an automated GitHub Actions CI/CD pipeline deploying zero-downtime rolling container updates to an Ubuntu VPS.
